- **飞书推送机器人_搭建流程与能力地图.md** —— 把"搭飞书机器人"拆成三层能力(平台配置/后端开发/消息卡片),看清自己缺什么、该学什么。

### 03_最终脚本(真正在跑的成品)
- **autohome_fetch.py** —— 每晚 23:59 抓取当天汽车之家资讯并存档(存 md + latest_news.json)。
- **autohome_send.py** —— 每天早 9:00 读存档,把资讯卡片推送到飞书群。⚠️ 归档版已抹去真实 webhook,复用时需填回自己的地址。
- 两脚本经 latest_news.json 解耦。实际部署在桌面,由两个 Windows 定时任务驱动。

### 04_职业资产(拔高到"这对我意味着什么")

## 系统当前运行状态(截至 2026-08-10)

- 路线:飞书群自定义机器人(webhook),个人账号即可,无需管理员审批。
- 自动化:两个 Windows 定时任务已配好并测试通过 —— 23:59 抓取存档 / 09:00 推送。
- 数据源:autohome.com.cn/all/(全部资讯列表页)。

## 维护须知(以后出问题看这里)

1. **电脑要开机**:定时任务只在电脑开机(或可唤醒)时跑。半夜关机则当次抓取跳过。
2. **卡片空了/发的是旧内容**:多半是汽车之家改版导致抓取选择器失效——需重新勘察 /all/ 页面结构、调整 ARTICLE_RE 或 h3 选择逻辑。不是配置错。
3. **webhook 是机器人钥匙**:勿截图公开或外发,谁拿到都能往群里发消息。
4. **想发给老板**:把老板拉进这个群即可一起收到。
5. **想升级为全员推送**:需迁移到公司"千里速闻"自建应用,走 App ID/Secret 换 token 的鉴权流程(能力地图第二层核心,尚未实操)。
