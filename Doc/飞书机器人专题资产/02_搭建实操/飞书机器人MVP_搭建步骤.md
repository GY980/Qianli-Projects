# 飞书群机器人 · 汽车之家每日推送 MVP · 搭建步骤

> 目标:用你自己的飞书账号(非公司账号),搭一个群机器人,每天早上 9:00 自动把汽车之家最新文章推送到群里。
> 路线:群自定义机器人(webhook)—— 零审批、零权限配置、五分钟拿到地址。
> 配套脚本:`feishu_autohome_bot.py`
> 日期:2026-08-04

---

## 心态提示:分两步走,别一上来就啃最难的

这个 MVP 由两块拼成:**① 飞书推送(简单可靠)** 和 **② 抓汽车之家(脆弱易坏)**。
脚本里已经放了一个 `USE_FAKE_DATA` 开关,**建议顺序**:
1. 先 `USE_FAKE_DATA = True`,把「飞书群能收到卡片」这条链路 100% 跑通 —— 这一步几乎不会失败,能给你正反馈。
2. 再 `USE_FAKE_DATA = False`,去调真实抓取 —— 这一步可能要反复调选择器,属于正常。

---

## 第一步 · 建群 + 加机器人,拿到 webhook(约 5 分钟)

1. 用你自己的飞书,新建一个群(可以只拉自己,或起名叫「机器人测试」)。
2. 进群 → 右上角「设置」→ 找到「群机器人」→「添加机器人」。
3. 选择 **「自定义机器人」**(Custom Bot)。
4. 给它起个名字和头像(比如「汽车之家资讯」),点添加。
5. 系统会给你一个 **Webhook 地址**,形如:
   `https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxxxx-xxxx-xxxx`
   **复制它。** 这就是脚本里要填的 `FEISHU_WEBHOOK_URL`。
6. (可选安全设置)飞书会让你选安全校验方式:可以先选「自定义关键词」并填一个词(比如「资讯」),那么之后发的消息里必须包含这个词才会成功 —— 脚本卡片标题里有「资讯」二字,已满足;若你嫌麻烦也可先不设。

> 注:这一步不需要任何管理员权限,你的个人飞书账号就能完成。

---

## 第二步 · 准备 Python 环境(约 5 分钟)

1. 电脑上装好 Python 3(官网 python.org 下载,安装时勾选「Add to PATH」)。
2. 打开命令行(Windows 用 PowerShell / CMD,Mac 用终端),装两个库:
   ```
   pip install requests beautifulsoup4
   ```
   - `requests`:发 HTTP 请求(拿网页、POST 给飞书)。
   - `beautifulsoup4`:解析网页 HTML,从中抽出文章标题和链接。

---

## 第三步 · 改脚本里的一处配置,先用假数据跑通

1. 用记事本 / VS Code 打开 `feishu_autohome_bot.py`。
2. 找到最上面配置区的 `FEISHU_WEBHOOK_URL`,把它换成你第一步复制的地址。
3. 确认 `USE_FAKE_DATA = True`(默认就是)。
4. 命令行里运行:
   ```
   python feishu_autohome_bot.py
   ```
5. 顺利的话,命令行会打印「✅ 推送成功」,同时你的飞书群里会弹出一张卡片。
   **看到这张卡片,就说明整条推送链路通了 —— 这是最重要的里程碑。**

如果失败,看命令行打印的飞书返回信息:
- 提示关键词相关 → 你在第一步设了自定义关键词,但消息不含该词。把关键词设成「资讯」或去掉该安全设置。
- 提示地址错误 / 404 → webhook 地址没复制对。

---

## 第四步 · 打开真实抓取

1. 把脚本里 `USE_FAKE_DATA` 改成 `False`。
2. 再运行一次。
3. 两种结果:
   - **抓到了**:群里收到真实文章,恭喜,继续第五步。
   - **没抓到 / 报错**:这是大概率会遇到的,不是你的错 —— 汽车之家页面结构和反爬会变。
     按脚本文件最底部「如何调试抓取」那段操作:F12 看真实的文章 `<a>` 标签,改 `fetch_autohome_news` 里的 `soup.select(...)` 那一行。
     实在啃不动时,可以先退回假数据,或换一个带 RSS 的稳定站点当数据源(那样抓取会简单可靠得多)。

---

## 第五步 · 设置每天早上 9:00 自动运行

脚本本身只是「运行一次就发一次」,要每天自动跑,需要让操作系统定时触发它:

**Windows(任务计划程序)**
1. 搜索并打开「任务计划程序」。
2. 「创建基本任务」→ 触发器选「每天」→ 时间设 09:00。
3. 操作选「启动程序」→ 程序填 `python`,参数填脚本的完整路径。
4. 完成。之后每天 9 点电脑开着就会自动跑。

**Mac / Linux(crontab)**
```
crontab -e
# 加一行(把路径换成你的实际路径):
0 9 * * * /usr/bin/python3 /路径/feishu_autohome_bot.py
```

> 局限:定时任务依赖你的电脑在 9 点时是开机的。要做到「云端 7×24 自动跑」,后面可以把脚本放到一台云服务器或用云函数,那是进阶话题,先不用管。

## 你在这个 MVP 里实际练到的能力(对应能力地图)

| 能力地图里的层 | 这个 MVP 里对应练到的 |
|---|---|
| 第二层 · HTTP 请求 | 用 requests 发 GET(抓网页)和 POST(推飞书) |
| 第二层 · JSON | 组装并序列化飞书卡片 JSON、解析返回结果 |
| 第三层 · 消息卡片 | 亲手写了一张 interactive 卡片(标题栏 + 正文 + 备注) |
| 工程能力 · 定时任务 | 用系统计划任务实现每天定点触发 |
| 工程能力 · 容错 | 抓取与推送解耦、假数据开关、失败信息打印 |

**注意**:群 webhook **没练到**自建应用那套「App ID/Secret 换 token」的鉴权流程 —— 因为 webhook 不需要 token。那部分要等你走「自己注册免费飞书团队 + 建自建应用」时才会用到(见下)。

---

## 下一步进阶方向(练完这个之后)

1. **换稳定数据源**:用带 RSS 的站点替代汽车之家,体会「好数据源让抓取变简单」。
2. **走自建应用完整流程**:用你个人身份免费注册一个飞书团队,自己当管理员,建自建应用、开机器人、批 `im:message` 权限、发布上线,亲手实现「换 tenant_access_token → 缓存刷新 → 调 im/v1/messages 发一对一消息」。这一步才补齐能力地图第二层的鉴权核心,而且学到的能无缝迁移回公司账号(那时你才具备真正「推给老板」的能力)。
3. **卡片交互**:给卡片加按钮,点了之后回调你的后端做事情。

---

## 一句话总结

群 webhook 是零门槛的练手场:**建群加机器人拿地址 → 改一行配置 → 先假数据跑通推送 → 再啃真实抓取 → 挂个定时任务。** 跑通后你就完整体验了「定时 → 拉取 → 组装卡片 → 推送」这条流水线,再往自建应用进阶时会轻松很多。
