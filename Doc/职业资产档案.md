## 2. 工作价值分层（本文件的核心，帮你决定"多做什么、少做什么"）

我把你入职以来的工作按**「价值 × 成长性」**分成四层。价值＝对业务的不可替代性；成长性＝能否沉淀、迭代、迁移到下一份工作。

### 🟢 A层 · 核心资产（应持续投入、做深做专）

这些是你的护城河，也是简历上最有分量的部分。

- **智驾企业标准（企标）撰写与评审闭环**。从SR到企标、组织FO评审、意见闭环——这是**有领域壁垒、有沉淀、可迁移**的工作。企标是公司级资产，署名工作含金量高。建议：主动沉淀一套"企标撰写方法论/checklist"，从"执行者"升级为"能定流程的人"。
- **智驾功能知识体系（12+功能 + L3准入/L4RT）**。你已覆盖从低速辅助到Robotaxi的完整谱系，这是稀缺的领域深度。建议：整理成个人知识库，未来可支撑产品经理、法规专家、行研等多个方向。

### 🟡 B层 · 高潜力（有成长性，值得升级做法）

做对了能进A层，做成一次性就滑到C层。

- **竞品智驾技术演进研究（华为/小鹏/理想）**。这是**从"整理"走向"洞察"的关键一跃**。如果只是罗列版本更新，价值有限；如果能提炼演进规律、推导技术路径（你已经在做），就是能拿去做行研、产品规划的硬能力。建议：固化成季度更新的"智驾技术雷达"，持续迭代。
- **NPS数据分析报告**。方法（帕累托、洞察）是可复用资产，但**别停在"做一次图表"**。建议：沉淀成可复用的分析模板，并跟踪"洞察→改进→下期NPS变化"的闭环，证明你的分析真正驱动了改进——这才是数据能力的高阶证据。
- **千里速闻资讯运营**。长期做、有产出（HTML页面、订阅号内容），但**单条推送的价值会递减**。升级方向见第4节，别让它停留在"搬运资讯"。

### 🟠 C层 · 维持性（必要但难沉淀，控制投入）

- **FDA数据整理 / FDA-SR对应关系**。基础数据治理，有必要但重复性高、壁垒低。建议：一次性做成模板或自动化脚本，之后少花时间。
- **上市车型及智驾版本迭代PPT**。信息聚合类，价值取决于是否加入你的判断。若只是排版汇总，尽快模板化。

### 🔴 D层 · 消耗型（低价值、可被替代，尽量减少或推动优化）

**坦率说，这类工作做多了会稀释你的履历，要警惕。**

- **用户问题整理（如OS7.2先享用户问题）**。纯资料搬运，无沉淀、无壁垒、随时可被他人替代。建议：要么推动它变成结构化的问题分类库（升级为可复用资产），要么争取交给他人/工具，把时间还给A、B层。
- **RAT预审议题分类整理（与FO确认状态、改状态）**。典型的"状态跟进"事务，价值低且不可迁移。建议：能否用一张共享表/看板让FO自己更新状态？把你从"人肉同步器"里解放出来。

> ⚠️ **每月自检提醒**：如果某个月你的时间超过 40% 花在 🟠C / 🔴D 层，请在当月复盘里标红，并想办法把这部分工作模板化、自动化或转交。助手在每月更新时也会主动帮你盯这条线。

### ⭐ 重复劳动工程化小故事（可直接用于面试/简历，STAR 结构）

> 用途：这是一段能讲出"自动化/工程思维"的完整故事，比"我会做HTML"有力得多。核心不是做图技能，而是**遇到重复痛点→不埋头多做→往上抽一层做成工具**的思维方式。

**S（情境）**：负责千里速闻智驾资讯的长期推送，需要反复产出资讯页面并导出为移动端长图分发。这是一件高频、重复的例行工作。

**T（任务）**：在保证质量的前提下，尽可能压缩每次制作的手工成本与不确定性，让自己从"重复搬砖"里解放出来。

**A（行动）——一条清晰的工程化演进**：
1. **手搓页面** → 改为**用工具直接生成 HTML**，去掉重复排版的体力活；
2. 导出环节最初用 **capture screen 手动截图**（尺寸不可控、易超平台像素上限、渲染不稳定）→ 改为在 HTML 里**内置「导出移动端长图」按钮**：用固定宽度+像素预算反推清晰度，自动保证不超限，并解决了渐变字渲染库选型（html-to-image 而非 html2canvas）等坑；
3. 把整套做法**沉淀为可复用的制作 skill / SOP**，从"每次凭记忆做"变成"照流程做"；
4. 进一步打通 **lark CLI + 飞书妙搭发布链路**，让页面能在企业平台正式发布/托管。

**R（结果与反思）**：从"每次手工做图"升级为"一次沉淀、长期复用的工具+流程"，单次制作时间和出错率显著下降。**更重要的是能力认知**：我意识到自己真正积累的不是"做长图"这个技能，而是"**把重复劳动一步步工程化/自动化**"的思维——这种能力可迁移到任何重复性工作（如数据处理、报表、看板）。

**一句话版本（面试口述用）**：
> "我把一件高频重复的资讯推送工作，从纯手工一步步做成了半自动化流程：手搓→自动生成HTML→内置导出工具→沉淀成标准流程→打通企业平台发布。这个过程让我发现，我擅长且享受的其实是'把重复劳动工程化'这件事本身。"

## 4. 职业发展方向（基于你现有能力的三条可能路径）

你的能力组合很有意思：**既懂智驾技术功能定义，又懂标准/合规，还有数据和内容能力**。这是个稀缺的交叉点。三条路径供探索：

**路径一：智驾标准/法规专家（最顺、壁垒最高）**
你已在企标、L3准入、L4RT上有积累。国内L3/L4法规正在快速落地，懂功能定义又懂标准编制的人稀缺。下一步：深入 UN-R157、GB/T 智能网联相关国标、L3准入试点法规，争取参与团体标准/国标制定。这条路天花板高、越老越值钱。

**路径二：智驾产品经理 / 产品规划**
你的功能知识体系 + 竞品技术演进研究 + NPS用户洞察，正好是产品经理的三大输入。下一步：把"技术演进研究"和"NPS洞察"打通，产出"用户痛点→功能规划"的建议，主动向产品团队靠拢。

**路径三：智驾行业研究 / 战略分析**
竞品架构演进 + 资讯运营 + 数据分析，是行研的底子。下一步：把千里速闻从"资讯搬运"升级为"带观点的行业分析"，积累对外可发表的研究成果。

> 建议：先把路径一做为主干（壁垒最高、最难被替代），路径二/三作为能力延展，三者共享你的"智驾功能知识体系"这个底座。

### ⭐ 方向自省记录（2026-08-07，本人主动反思，很重要）

**本人现状与真实诉求（原话整理）**：文档/企标是过往经历，属于"擅长但在舒适区、并不喜欢"的工作，且易被 AI 取代；真正向往的是**数据看板 / 自动化 / 数据分析**方向，但一直没机会真正接触，又担心这类工作 AI 替代性太强。核心诉求是找到"**喜欢 + 擅长 + 不易被取代 + 能赚钱**"的方向，并自问"是不是想要太多了"。

**助手的判断（供本人后续复盘）**：
1. **不是想得太多**——这是完整合理的职业标准；问题只是想一步到位同时满足四项，而现实是逐步逼近。
2. **"工作就该做不喜欢但擅长的"是危险的自我说服**：早期靠擅长立足，中期必须向"喜欢且擅长"迁移，因为"不易被取代"来自只有喜欢才愿投入的深度。
3. **"数据分析易被 AI 取代"只说对一半**：会被取代的是做图/写脚本/清洗数据等执行动作；不会被取代的是"知道问什么、判断哪个数据是噪音、把数据翻译成业务决策"。本人**已有数据底子**（6月NPS帕累托、去重→映射方法论），缺的不是能力，是"能持续做且与领域优势结合的场景"。
4. **关键结论——别把"数据"和"智驾"当二选一**：本人最稀缺、最难被替代的组合是二者交叉——"**既懂 L2–L4 智驾功能定义与合规、又能用数据驱动判断的人**"。AI 不懂智驾、纯数据分析师不懂功能边界，此交叉点是护城河。
5. **企标的真实定位**：不是"写文档"，而是守住让数据能力变得不可替代的**领域底座**；丢掉它会退化成"通用数据分析师"，反而更易被替代。短期先把评审中的企标闭环（唯一 A 层筹码 + 谈判资本）。

**可自己创造的高价值场景（不必等公司给机会、不必换工作）**：把 NPS 分析从"做一次图表"升级为「**智驾功能质量数据看板**」——持续追踪各功能用户抱怨 → 对应到自己写的标准条款 → 驱动下一版改进。这一件事同时命中：数据看板（喜欢）+ 自动化（想学）+ 智驾领域（壁垒）+ 价值闭环（可证明），且别人造不出来。**行动建议**：主动向领导提出立项此看板；这既是想要的方向，又用现有领域优势构筑了 AI 与他人都难替代的壁垒。
